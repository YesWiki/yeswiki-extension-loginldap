# yeswiki-extension-loginldap

 - [English](#english)
 - [Français](#français)

## English

[YesWiki](https://yeswiki.net/) extension replacing the login form by an
authentication against an LDAP directory.

### Authors

 - Florian Schmitt
 - and all contributors indicated on this page : <https://github.com/YesWiki/yeswiki-extension-loginldap/graphs/contributors>

### Install

In page `GererMisesAJour` on your YesWiki website, search extension `loginldap` and install it.

The extension installs safely. As long as `ldap_host` and `ldap_port` are not set, it
stays inactive: a message reports the missing configuration and the usual YesWiki
login form keeps working.

### Usage

Usage help is described in `http://example.com/?doc/#tools/loginldap/en/README.md` (replacing `http://example.com/?` by the `baseUrl` of your wiki). The same file can be found also here : https://github.com/YesWiki/yeswiki-extension-loginldap/blob/master/docs/en/README.md

## Français

Extension [YesWiki](https://yeswiki.net/) qui remplace le formulaire de connexion par
une authentification sur un annuaire LDAP.

### Auteurs

 - Florian Schmitt
 - et tous les contributeurs et toutes les contributrices indiqués sur cette page : <https://github.com/YesWiki/yeswiki-extension-loginldap/graphs/contributors>

### Installation

Dans la page `GererMisesAJour` de votre YesWiki, recherchez l'extension `loginldap` et installez-la.

L'extension s'installe sans rien casser. Tant que `ldap_host` et `ldap_port` ne sont
pas renseignés, elle reste inactive : un message signale la configuration manquante et
le formulaire de connexion habituel de YesWiki continue de fonctionner.

L'aide sur l'utilisation peut être trouvée sur `http://example.com/?doc/#tools/loginldap/fr/README.md` (en remplaçant `http://example.com/?` par `baseUrl` de votre wiki).
